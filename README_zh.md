# AirPlay Deck

把 Steam Deck / Linux 变成 **AirPlay 接收端**（基于 [UxPlay](https://github.com/FDH2/UxPlay)）。**桌面模式与 SteamOS 游戏模式均正式支持。**

## 功能概览

- **桌面模式**与**游戏模式**均可投屏（游戏模式在 Steam 中添加为非 Steam 游戏后启动）
- 桌面「窗口 / 自动」模式会对竖屏流（如 iPhone 竖拍）**自动最大化**投屏窗口；游戏模式强制全屏（`-fs`）
- 投屏时长片保活：systemd-inhibit + 游戏模式下宿主 `xset` 周期性防熄屏
- 图形界面 8 种语言，跟随系统
- 一键检查环境、安装/更新容器内 UxPlay、导出诊断日志

## 使用方式

### 桌面模式

1. 下载并赋予执行权限后，在桌面直接运行 AppImage。
2. 打开「检查与日志」确认容器可用（首次需联网）。
3. 回主页打开开关；在 iPhone / iPad 控制中心 → 屏幕镜像 → 选择本机名称。
4. 显示模式可选窗口 / 全屏 / 自动；竖屏流在窗口模式下会自动铺满。

### 游戏模式（SteamOS）

1. 将 AppImage 添加为 Steam「非 Steam 游戏」，从游戏模式启动。
2. 同样在主页打开接收开关，用手机屏幕镜像连接。
3. 投屏默认全屏。观看长视频时请保持设置中的「投屏时保持屏幕常亮」。
4. 若偶发鉴权/黑屏问题，可导出日志；多数情况下重试或改用桌面模式即可。

## 常见问题（简）

| 现象 | 建议 |
|------|------|
| 手机找不到设备 | 确认同网段、防火墙未拦 mDNS/Bonjour；可重启 Avahi |
| 游戏模式有声无画 / Authorization required | 导出日志；本版以宿主 uid 跑探针与 uxplay。仍失败可改用桌面模式 |
| 游戏模式长片几分钟后画面黑、声音还在 | 打开「投屏时保持屏幕常亮」；需宿主有 `xset` |
| 桌面竖屏画面很小 | 窗口/自动模式应自动最大化；可安装 `wmctrl` 或 `xdotool`，或改用全屏 |
